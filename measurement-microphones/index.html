Measurement microphones: what to buy, and where

Perfect Soup measures your room from 30 to 100 positions, and every one of those measurements arrives through the microphone. These are the three we recommend — one for value, one for the reference tier, and one for systems with no XLR input — with live prices from the dealers that publish them.

Our picks

The beyerdynamic MM 1 is the one to buy if you are calibrating your own room and want to spend once. Step up to the Earthworks M23R if you measure other people’s rooms, need mics that match each other, or want a calibration file traceable to the individual unit. If your system has no XLR input at all, the miniDSP UMIK-2 is USB and needs no interface — read the note below before you buy one.

beyerdynamic MM 1

The value pick. Omnidirectional, ±1.5 dB from 50 Hz to 16 kHz, ships with an individual frequency-response sheet. Needs an interface with phantom power.

Before you buy a USB mic

The wizard currently needs the microphone input and the speaker outputs on a single audio device. On macOS that is solved today — an Aggregate Device in Audio MIDI Setup combines a USB mic with your output and the wizard sees one device. On Windows it means a full-duplex ASIO interface, so a USB mic paired with separate speaker outputs is not supported yet; two-device support is planned for a future Calibration Wizard update. If you are on Windows today, choose one of the XLR mics — they need an interface supplying 48 V phantom power, and the supported combinations are listed in the FAQ.

Other odd bits

A stand is mandatory — hand-holding the mic drifts between sweeps and adds handling noise on every one of them. For the cable, buy the length that reaches every position from wherever the interface lives: 25 ft / 7.5 m, and a balanced XLR run that long costs you nothing in quality.
